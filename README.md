# Aula de Git: Introdução

Este repositório foi criado para praticar os conceitos fundamentais de versionamento de código com Git e GitHub.

## Atividades Realizadas
1. **Criação do Repositório**: Repositório público no GitHub.
2. **Commits Iniciais**: Criação e alteração do arquivo `perfil.py`.
3. **Simulação de Conflito**: Alteração simultânea local e remota no mesmo trecho do código.
4. **Resolução de Conflito**: Resolução manual unificando as alterações.
5. **Desafio Extra**: Criação de branch `nova-feature`, adição de novo arquivo, Pull Request e Merge.
